# Historical design documents

These files preserve the original personal prototype requirements and proposals.
They are not current installation, configuration or implementation instructions.
Some described components never existed, and some examples differ from the code.

- `PRD.md`: personal-use requirements, including volatile storage.
- `TECHNICAL.md`: early implementation proposal and unimplemented command ideas.
- `TECHNICAL_last_focus_line.md`: alternatives considered for cursor tracking.
- `example-record.yaml`: historical YAML illustration of record fields.

Use the root README and `docs/RECORD-FORMAT.md` for the supported behavior.
